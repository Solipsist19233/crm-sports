# CRM Спортивна Школа (Гімнастика та Акробатика)

Сучасна система управління спортивною школою, що дозволяє контролювати відвідуваність, оплати, абонементи та формувати фінансову звітність.

## 🚀 Основні можливості

### 📊 Дашборд (Головна сторінка)
- **Статистика в реальному часі**: Загальна кількість учнів, активні атлети, кількість присутніх сьогодні.
- **Контроль боргів**: Картка, що підсвічує кількість неоплачених занять. При натисканні — перехід до списку боржників.
- **Сповіщення**: Попередження про закінчення терміну дії абонементів та страховок.

### 👥 Управління учнями
- **Повна анкета**: Прізвище, ім'я, дата народження, контакти батьків.
- **Контроль документів**: Галочки для відстеження медичних довідок, підписаних договорів та термінів страхування.
- **Статуси**: Автоматичне підсвічування "проблемних" зон (червоний колір, якщо документа немає або страховка закінчилася).

### 📅 Журнал відвідувань
- **Конструктор призначень (Admin)**: Створення розкладу на конкретні дати для конкретних тренерів.
- **Зручна відмітка**: Можливість відмітити "Присутній" та "Оплачено" в один клік.
- **Автоматичне списання**: Якщо вибрано тип оплати "Абонемент", система автоматично знімає одне заняття при підтвердженні.
- **Гнучкість**: Можливість зберігати журнал навіть з неоплаченими заняттями (борги фіксуються в історії).

### 📜 Історія та Звітність
- **"Заморожена" історія**: Дані в історії зберігаються текстом. Навіть якщо видалити групу або призначення, історія пам'ятатиме назву групи та тренера, які були на момент заняття.
- **Фінансовий звіт (PDF)**: Генерація професійного ландшафтного звіту з рамками, розрахунком прибутку (тільки для разових та індивідуальних занять) та підсумками за період.
- **Фільтрація**: Пошук за датами, тренерами, учнями або статусом оплати (борги).

## 🛠 Технічний стек

**Backend:**
- **FastAPI**: Високопродуктивний Python фреймворк.
- **SQLAlchemy**: ORM для роботи з базою даних (PostgreSQL на Railway, SQLite локально).
- **Pydantic**: Валідація даних.
- **JWT**: Безпечна авторизація через токени.

**Frontend:**
- **Vanilla JS**: Чистий JavaScript для максимальної швидкості.
- **CSS3**: Адаптивна верстка (Mobile-first).
- **html2pdf.js**: Генерація звітів на стороні клієнта.

## ⚙️ Як це працює (Логіка системи)

1. **Підготовка**: Адмін створює **Прайс-лист** (абонементи, разові заняття) та **Групи**.
2. **Призначення**: Адмін формує "Призначення" — план заняття (дата + група + тренер + список учнів).
3. **Проведення**: Тренер заходить у вкладку **Відвідування**, відкриває потрібну групу, відмічає присутніх та статус оплати, натискає "Зберегти та підтвердити".
4. **Списання**: Система перевіряє: якщо стоїть "Абонемент" + "Оплачено", у учня знімається 1 заняття в його активному абонементі.
5. **Фіксація**: Копія даних лежить в **Історії**, де вона доступна для перегляду та PDF-експорту навіть після видалення самого плану заняття.

## 📦 Розгортання (Deployment)

### Локальний запуск
1. Встановити залежності: `pip install -r requirements.txt`
2. Запустити ініціалізацію БД: `python backend/init_db.py`
3. Запустити сервер: `python backend/main.py` або `uvicorn main:app --reload`

### Railway.app (Production)
Система налаштована на автоматичний деплой. При старті `main.py` автоматично проводить міграції:
- Додає колонки `group_id`, `trainer_id`, `is_paid`, `payment_choice` до таблиці відвідувань.
- Додає поле `has_contract` до таблиці учнів.
